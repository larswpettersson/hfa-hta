Add and edit tasks

C / S / D
Add child / sibling / duplicate
Enter
Start / apply description edit
Esc
Cancel edit, or clear selection / close column picker
Delete / Backspace
Delete selected task (not root)

TTA columns

Click a header
Edit the column's name and description (or Enter on a focused header)
✕ at the end of a row
Delete the TTA row (a task's last row is cleared instead); Ctrl/⌘+Z undoes it
Columns… → + Column…
Add a column. Any column except Task Step can be deleted; Reset restores the HEI columns

Navigate and restructure

← ↑ → ↓
Move the indication (the hovered shadow) to the nearest task in that direction on the screen. Arrows never select or move anything
Ctrl/⌘ + Enter
Select the indicated task (the same as a click)
Enter / F2
Edit the text of the indicated task
Alt/Option + ↑
Selected task: outdent (up a level)
Alt/Option + ↓
Selected task: indent under the previous sibling (down a level)
Alt/Option + ← →
Selected task: move earlier or later among siblings
Space + drag
Pan the HTA canvas
